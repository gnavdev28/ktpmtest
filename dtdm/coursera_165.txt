Câu 165: A solutions architect must create well-defined governance standards for a company that has multiple AWS accounts. The company needs centralized infrastructure logging for all AWS accounts. In addition, the company’s chief information security officer (CISO) would like to have a measurement that applies a circuit breaker to stop Amazon Elastic Compute Cloud (Amazon EC2) API activities if the billing alarms indicate suspicious activity. The company intends to use AWS Organizations. Which architectural scenario should the solutions architect propose to meet the company’s needs in the MOST effective way? (Một kiến trúc sư giải pháp phải tạo ra các tiêu chuẩn quản trị được xác định rõ ràng cho một công ty có nhiều tài khoản AWS. Công ty cần ghi nhật ký cơ sở hạ tầng tập trung cho tất cả các tài khoản AWS. Ngoài ra, giám đốc an toàn thông tin (CISO) của công ty muốn có một biện pháp áp dụng cầu dao điện (circuit breaker) để dừng các hoạt động API Amazon EC2 nếu cảnh báo thanh toán cho thấy hoạt động đáng ngờ. Công ty dự định sử dụng AWS Organizations. Kịch bản kiến trúc nào mà kiến trúc sư giải pháp nên đề xuất để đáp ứng nhu cầu của công ty theo cách hiệu quả NHẤT?)
* A. Enable AWS CloudTrail for all accounts in AWS Organizations. Use Organizations to centralize all logs into one Amazon Simple Storage Service (Amazon S3) bucket. As the circuit breaker, use service control policies (SCPs) that have an explicit deny for Amazon EC2 API activity. These SCPs can then be applied to the root organizational unit (OU) as needed. (Bật AWS CloudTrail cho tất cả các tài khoản trong AWS Organizations. Sử dụng Organizations để tập trung tất cả nhật ký vào một bộ chứa Amazon S3. Đối với cầu dao điện, hãy sử dụng các chính sách kiểm soát dịch vụ (SCP) có từ chối rõ ràng đối với hoạt động API Amazon EC2. Sau đó, các SCP này có thể được áp dụng cho đơn vị tổ chức (OU) gốc nếu cần.)
B. Enable AWS CloudTrail for all accounts in AWS Organizations. Use Organizations to centralize all logs into one Amazon Simple Storage Service (Amazon S3) bucket. Use multi-factor authentication (MFA) devices for every user in AWS IAM Identity Center (successor to AWS Single Sign-On). (Bật AWS CloudTrail cho tất cả các tài khoản trong AWS Organizations. Sử dụng Organizations để tập trung tất cả nhật ký vào một bộ chứa Amazon S3. Sử dụng các thiết bị xác thực đa yếu tố (MFA) cho mọi người dùng trong AWS IAM Identity Center.)
C. Enable AWS CloudTrail for only the production accounts in AWS Organizations. Use Organizations to centralize logs into one Amazon Simple Storage Service (Amazon S3 bucket). For single sign-on, use AWS IAM Identity Center (successor to AWS Single Sign-ON). (Chỉ bật AWS CloudTrail cho các tài khoản sản xuất trong AWS Organizations. Sử dụng Organizations để tập trung nhật ký vào một bộ chứa Amazon S3. Đối với đăng nhập một lần, hãy sử dụng AWS IAM Identity Center.)
D. Enable AWS CloudTrail for all accounts in AWS Organizations. Use Organizations to centralize logs in one Amazon Simple Storage Service (Amazon S3) bucket. As the circuit breaker, use AWS Identity and Access Management (IAM) policies on each account that have an explicit deny for Amazon EC2 API activity. The IAM policies can then be applied to the root organizational unit (OU) as needed. (Bật AWS CloudTrail cho tất cả các tài khoản trong AWS Organizations. Sử dụng Organizations để tập trung nhật ký vào một bộ chứa Amazon S3. Đối với cầu dao điện, hãy sử dụng các chính sách IAM trên mỗi tài khoản có từ chối rõ ràng đối với hoạt động API Amazon EC2. Sau đó, các chính sách IAM có thể được áp dụng cho đơn vị tổ chức (OU) gốc nếu cần.)
